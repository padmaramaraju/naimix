# naimix documentation

Static HTML. No build step, no server needed.

**Open it:** double-click `index.html`, or from the project root run `npx serve docs` / `python3 -m http.server -d docs 8080`.

## Layout

| Path | What |
|---|---|
| `index.html`, `getting-started/`, `concepts/`, `guides/`, `tutorials/`, `deployment/`, `reference/` | The pages |
| `assets/nav.js` | **The navigation.** Add a page to the `NAV` list at the top and it appears in the sidebar, search, and prev/next links |
| `assets/style.css` | Styling (light and dark) |
| `videos/` | Tutorial videos (MP4) |
| `images/` | Poster images and screenshots |

## Adding a page

1. Copy any existing page. Keep the `<article>` wrapper and the two `assets/` links (adjust `../` to the folder depth, and set `data-root` to match).
2. Add an entry to `NAV` in `assets/nav.js`.

## Adding a video

Put an H.264 MP4 in `videos/`, then place this where it should appear:

```html
<figure class="video" data-src="videos/my-tutorial.mp4" data-poster="images/my-tutorial.png" data-title="What it shows"></figure>
```

`data-src` is always relative to `docs/`. Until the file exists, the page shows a placeholder naming the path to use.

Videos included: `videos/xml-gateway.mp4` and `videos/developer-console-tour.mp4` (each with a `.vtt` captions file and a poster in `images/`). They were generated by the scripts in `recorder/`; see its README to re-record them after UI changes.
