Ops Console

Read-only runtime observability for a running instance, intended for QA and Production. It is deliberately separate from the Developer Console.

Not the Developer Console

TokenCONSOLE_TOKENOPS_TOKEN

Enable it

  1. Set OPS_TOKEN in the instance's environment to a long random string.
  2. Open /ops and enter the token.

With no OPS_TOKEN, /ops/api/* responds 503 instead of running unauthenticated.

Protect it further in production. The token alone is probably not enough for a surface that exposes environment details. Put /ops behind your network controls, VPN or an authenticating proxy.

Every response carries an instanceId: INSTANCE_ID if set, otherwise hostname:pid. Data lives in that process's memory and resets on restart.

curl -H "Authorization: Bearer $OPS_TOKEN" http://localhost:4000/ops/api/system
