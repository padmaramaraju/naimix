Installation

Set up a machine from scratch to build, test and run naimix. Written mainly for macOS, with notes for Linux and Windows.

1. Install nvm

Use nvm rather than installing Node directly. naimix needs a specific Node version range and nvm lets you switch without conflicts.

# Option A: Homebrew (macOS)
brew install nvm
# Add the lines Homebrew prints to ~/.zshrc, then restart your terminal.

# Option B: official install script (macOS/Linux)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

On Windows use nvm-windows instead. Verify with nvm --version.

2. Install Node.js 22 or 24

nvm install 22
nvm use 22
nvm alias default 22

Do not use the newest Node release. better-sqlite3 compiles a native addon against V8, and brand-new Node versions can break it. Node 22 and 24 are known good. package.json declares node >= 24 as its target, and the build scripts target Node 24.

Check with node -v and npm -v.

3. Native build tools

npm install tries a prebuilt binary first and compiles from source only as a fallback. Having build tools ready means the fallback will not fail.

PlatformCommand
macOSxcode-select --install
Debian / Ubuntusudo apt-get install -y build-essential python3
Windows"Desktop development with C++" workload from Visual Studio Build Tools, plus Python 3

4. Get the code and install dependencies

git clone <repo-url> naimix
cd naimix
nvm use 22
npm install
cp .env.example .env

5. Optional dependencies

  • Folder picker on Linux: the console's "Browse…" button needs zenity (sudo apt-get install -y zenity). macOS and Windows need nothing.
  • LDAP tests: npm run test-ldap runs a local OpenLDAP server and needs Docker Desktop.

6. Verify the install

npx tsc --noEmit      # typecheck
npm run build:qa      # QA bundle
npm run build:prod    # production bundle
npx vitest run        # test suite
npm run dev           # full dev server (console + data plane)

If all of those succeed, the install is good. Having trouble? See Troubleshooting.
