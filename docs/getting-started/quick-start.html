Quick start

Run the bundled demo and call your first endpoint.

Create your deployment file

naimix only serves the apps listed under mounts in deployment.yaml. Without that file the server starts with no routes (and logs a warning). Create it once:

cp .env.example .env
cp deployment.yaml.example deployment.yaml

Then edit deployment.yaml so it points at the bundled demo config and mounts the demo app:

configDir: config        # resolved against the folder you run npm from
mounts:
  - app: default
    basePath: /

The file is per-machine and is not committed to Git. See Mounting apps on a server.

Start the demo

You need two terminals. The first runs a demo backend that exposes the same customer data as JSON, XML, SOAP and SQLite. The second runs naimix itself.

# Terminal 1
npm run mock-backend

# Terminal 2
npm run dev

Call the bundled examples

curl http://localhost:4000/api/json/customers/1
curl http://localhost:4000/api/json/customers
curl http://localhost:4000/api/xml/customers/2
curl http://localhost:4000/api/soap/customers/3
curl http://localhost:4000/api/sql/customers/1
curl http://localhost:4000/api/sql/customers

curl http://localhost:4000/__endpoints   # what is currently registered
curl http://localhost:4000/healthz       # status + route count

All four backends return the same customer shape, because each integration maps its own backend's format onto a common JSON structure.

Try an authenticated endpoint

curl -X POST http://localhost:4000/auth/login/demoLogin \
  -H 'Content-Type: application/json' \
  -d '{"username":"demo","password":"demo123"}'
# → {"token":"<opaque session token>","expiresAt":1234567890000}

curl http://localhost:4000/api/authed/echo \
  -H 'Authorization: Bearer <token from above>'

See Caller authentication for how this works.

Open the Developer Console

  1. Set CONSOLE_TOKEN in .env to any random string.
  2. Restart npm run dev.
  3. Open http://localhost:4000/console and paste the token when prompted.

If CONSOLE_TOKEN is unset, the console API responds 503 instead of running unauthenticated.

Compiled run and tests

npm run build && npm start   # compiled run of the full app
npm test                    # automated tests (starts its own mock backend)
