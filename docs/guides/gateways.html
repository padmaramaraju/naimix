Gateways

A gateway is a reusable connection to one backend. Integrations refer to it by name, so base URLs and credentials live in one place.

This video is also available with a step-by-step script on the tutorial page.

Gateway kinds

kindRequired fieldNotes
jsonbaseUrlJSON REST APIs. A relative integration url is appended to baseUrl.
xmlbaseUrlPlain XML-over-HTTP. Responses are parsed by fast-xml-parser.
soapwsdlSOAP operations via the WSDL.
sqlclient, connectionClients: pg, mysql2, mssql, sqlite3, better-sqlite3.

A gateway without a baseUrl or wsdl is not useful, so both the schema and the console enforce it. An integration can still call a fully custom absolute URL without any gateway.

Example gateways.yaml

gateways:
  crmJson:
    kind: json
    baseUrl: ${env.CRM_BASE_URL}
    headers:
      Authorization: "Bearer ${env.CRM_TOKEN}"
    commonParams:               # available as {name} in every integration on this gateway
      tenant: acme
      region: ${env.DEPLOY_REGION}

  crmSoap:
    kind: soap
    wsdl: ${env.CRM_WSDL_URL}

  mainDb:
    kind: sql
    client: pg
    connection:
      host: ${env.DB_HOST}
      user: ${env.DB_USER}
      password: ${env.DB_PASSWORD}
      database: ${env.DB_NAME}

  crmJsonAuthed:
    kind: json
    baseUrl: ${env.CRM_BASE_URL}
    requiresAuth: myProvider    # see Caller authentication

Keep secrets out of config

${env.VAR_NAME} is resolved once at startup from process.env (loaded from .env). Only the variable name is committed, never the secret.

Common parameters

commonParams are defaults every integration on the gateway can use as {name} in its URL, headers, query, SOAP args or SQL bindings. They sit underneath an integration's own input, so an integration that declares a parameter with the same name overrides the default for that call. Use them for things every call needs, such as a tenant id or region.

Creating one in the console

  1. Open Gateways in the Shared Collection and click + Add.
  2. Enter a name and choose the kind. The fields below change to match.
  3. Fill in the base URL (or WSDL, or connection), optional headers, and common parameters.
  4. Click Save gateway. It is immediately available to every integration.
