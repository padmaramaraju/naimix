What naimix does

Every backend integration is defined in a config file, not code. To expose a new API you describe the backend to call, the parameters it accepts, and how to map the backend's response onto the JSON you want to return. naimix then:

  1. Receives a request on a public route you defined.
  2. Extracts and validates the input (path, query, header, body, or environment).
  3. Calls the backend (json, xml, soap or sql), substituting your parameters.
  4. Maps the raw response onto your output shape and returns JSON.
