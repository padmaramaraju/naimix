Config file reference

A compact summary of every config file. Details and examples are in the guides.

Workspace layout

gateways.yaml
authProviders.yaml
integrations/<id>.yaml
apps/<id>.yaml
transforms/<name>.ts / .js

deployment.yaml          # per machine, not in the workspace, not in Git
.env                     # per machine, not in Git

Any string value may contain ${env.VAR_NAME}, resolved once at startup.

deployment.yaml

KeyMeaning
configDirWorkspace folder. Relative paths resolve against the working directory.
mounts[].appApp id to serve.
mounts[].basePathPublic prefix for that app's routes.

gateways.yaml

KeyApplies toMeaning
kindalljson | xml | soap | sql
baseUrljson, xmlRequired.
wsdlsoapRequired.
clientsqlpg | mysql2 | mssql | sqlite3 | better-sqlite3
connectionsqlKnex connection object (host, user, password, database, or filename).
headersjson, xmlSent on every request.
commonParamsallDefault {name} values for every integration on the gateway.
requiresAuthallName of an auth provider callers must log in through.

authProviders.yaml

kindKey fields
basicLoginloginUrl, method, tokenPath, refreshTokenPath, expiresInPath
oauth2tokenUrl, grantType (password | client_credentials | authorizationCode), clientId, clientSecret; for authorizationCode also authorizationUrl, redirectUri, clients[]
ldapurl, bindDn, bindPassword, searchBase, searchFilter, optional group and attributes settings, tokenSecret, tlsRejectUnauthorized; or userDnTemplate for direct bind

Integration

KeyMeaning
idUnique id.
descriptionOptional.
input[]name, in, required, type, default, envVar, description
backendOne of: json (url, method, headers, query, body, timeoutMs), xml (same, body is an XML string), soap (operation, args, endpoint), sql (query, or generated: table, operation, primaryKey, columns). All accept gateway.
output.fields[]target, source, default, transform; or kind: array with root and nested fields
output.postProcess{ name } of a custom function.

App

KeyMeaning
id, nameStable slug and display name.
routes[]id, method, path, description, integration

Parameter substitution

WhereSyntax
json / xml / soap fields{paramName}
sql queries:paramName
Environment values in config${env.VAR}
Backend token from the caller's session{__authToken}

The authoritative definitions are the TypeScript types in src/types/config.ts and the schemas in src/config/schema.ts.
