Environment variables

Set these in .env (copied from .env.example) or in the server's environment.

Server

VariablePurpose
PORTPort to listen on. Default 4000.
LOG_LEVELfatal, error, warn, info, debug or trace.
MAX_REQUEST_BODY_SIZEMaximum JSON or urlencoded body size. Default 10mb. Raise it if a real payload trips "request entity too large".
INSTANCE_IDLabel returned by the Ops API. Defaults to hostname:pid.

Console tokens

VariablePurpose
CONSOLE_TOKENDev build only. Enables the Developer Console and is the bearer token for /console/api/*. Unset means the console API returns 503. Not read at all by QA and Production.
OPS_TOKENBearer token for the Ops Console (/ops/api/*). Read by all builds. Unset means 503.

Where config is loaded from

VariablePurpose
DEPLOYMENT_FILEPath to deployment.yaml. Default deployment.yaml in the working directory.
CONFIG_DIRWorkspace folder holding integrations/, apps/, gateways.yaml, authProviders.yaml, transforms/. Used when deployment.yaml has no configDir.
INTEGRATIONS_DIR, APPS_DIR, GATEWAYS_FILE, AUTH_PROVIDERS_FILE, TRANSFORMS_DIRLegacy per-piece overrides, used only when neither of the above is set. Defaults are under config/.

Priority in the dev build: configDir in deployment.yaml, then CONFIG_DIR, then the legacy variables. QA and Production skip the deployment.yaml configDir and start from CONFIG_DIR or the legacy variables, but still read mounts from deployment.yaml.

Demo settings

Variables starting with DEMO_ only feed the bundled demo config. Replace them with your real backends' variables.

VariableUsed for
DEMO_JSON_BASE_URL, DEMO_XML_BASE_URL, DEMO_SOAP_WSDL_URL, DEMO_SQLITE_PATHThe mock backend's four formats.
DEMO_OAUTH_CLIENT_SECRET, DEMO_OAUTH_CODE_REDIRECT_URIThe mock OAuth provider.
DEMO_LDAP_URL, DEMO_LDAP_BIND_PASSWORD, DEMO_LDAP_TOKEN_SECRETThe local OpenLDAP test directory.

Never commit .env. It is already in .gitignore.
