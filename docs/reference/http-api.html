HTTP API

The routes naimix itself provides, besides the ones you define.

Always available

RouteDescription
GET /healthzStatus and how many routes loaded.
GET /__endpointsLists every registered route: id, method, path, description, backend type. Useful to confirm a change took effect.
POST /auth/login/{provider}Log in. Body {"username","password"}. Returns {"token","expiresAt"}.
POST /auth/logoutInvalidate the session for the bearer token.
GET /auth/oauth/{provider}/startBegin an OAuth authorization-code login. Open in a browser. Parameters: app, return_to, optional state.
/ops, /ops/api/system, /ops/api/envOps Console. Requires OPS_TOKEN.

Dev build only: /console

The Developer Console UI is at /console. Its REST API at /console/api/* requires Authorization: Bearer <CONSOLE_TOKEN>.

ResourceRoutes
IntegrationsGET/POST /integrations, GET/PUT/DELETE /integrations/:id
GatewaysGET/POST /gateways, GET/PUT/DELETE /gateways/:name, plus connection test and CRUD generation actions
Auth providersGET/POST /auth-providers, GET/PUT/DELETE /auth-providers/:name
Apps and routesGET/POST /apps, GET/PUT/DELETE /apps/:id, route create/update/delete under /apps/:appId/routes
FunctionsGET/POST /functions, GET/PUT/DELETE /functions/:name
SettingsGET/PUT /settings, folder browsing for the workspace picker
SessionsList and revoke active caller sessions
ExportGET /export/openapi.json, GET /apps/:appId/export/openapi.json, GET /export/mcp-server
OtherGET /meta, POST /test-mapping, POST /reload

The exact routes are defined in src/server/consoleApi.ts.

Errors

All errors have the shape { "error", "message", "backendBody"? }.

StatusWhen
400Bad or missing input (ValidationError).
401Missing, invalid or expired caller session on an auth-required route.
409Console only: deleting something that is still referenced.
backend statusA backend HTTP error is passed through with its original status where available.
502Backend error with no usable status.
503Console or Ops API called with no token configured.
500Anything unexpected.
