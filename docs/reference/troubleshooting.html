Troubleshooting

Fixes for the problems you are most likely to hit.

Installation

npm install fails compiling better-sqlite3

Errors mention v8::Object, v8::Context or PropertyCallbackInfo. Your Node version is too new.

nvm use 22
rm -rf node_modules package-lock.json
npm install

ERESOLVE overriding peer dependency warning about esbuild

Harmless. npm resolved a version mismatch automatically. It is a warning, not an error.

esbuild: cannot execute binary file or Exec format error

node_modules was installed for a different OS or architecture (for example inside a container). Delete node_modules and reinstall on the machine that runs the build. Do not copy node_modules between machines.

EBADENGINE warnings

Your Node is older than the version in package.json's engines field, or a dependency raised its own minimum. Run node -v and upgrade with nvm.

Running

Every route returns 404, or the log says "No mounts found"

You have no deployment.yaml, or it has no mounts. Copy deployment.yaml.example and list the apps to serve. See Mounting apps.

A route exists in the console but returns 404

The app containing it is not mounted, or the basePath differs from what you are calling. Check GET /__endpoints for what is actually registered.

A hand-edited file is ignored

A file that fails validation is logged and skipped. Read the server log for Failed to load…. Then click Reload from disk in the console, or restart.

EADDRINUSE

Something is already on the port. Change PORT, or stop the other process (a previous npm run dev is the usual cause).

Demo endpoints fail with a connection error

The mock backend is not running. Start it in another terminal with npm run mock-backend.

Console

The console returns 503

CONSOLE_TOKEN is not set. Set it in .env and restart. The same applies to OPS_TOKEN and /ops.

The console says unauthorized

The saved token does not match. Sign out and enter the current CONSOLE_TOKEN.

"Browse folders…" does nothing on Linux

Install zenity. See Installation.

Deleting a gateway or auth provider is refused (409)

Something still references it. The response lists the dependents. Remove or repoint them first.

Comments disappeared from gateways.yaml

Saving through the UI rewrites the file in full. Keep notes elsewhere, or edit by hand and use Reload from disk.

Authentication

401 on an authenticated route

The session expired, was logged out, or the server restarted (sessions are in memory). Log in again. Also confirm you logged in through the provider that the route's gateway requires.

LDAP login fails

Confirm npm run test-ldap is running, the URL and bind DN are right, and the user exists under searchBase. For Active Directory use (sAMAccountName={username}).

OAuth code flow rejects the request

The app and return_to must exactly match an entry under the provider's clients. Also check that redirectUri is naimix's own address as registered with the provider.

Mapping

A field is empty or missing

Use Fetch sample response in the Try it panel and check the raw response. For XML, sources start at the outermost tag ($.customer…). For SQL, results are an array, so start $[0]….

XML numbers come back as strings

All XML text values are strings. Add transform: toNumber or toBoolean.

An XML list returns an object when there is only one item

The parser makes an array only for tags that repeat. Ask the backend to wrap single items consistently.
