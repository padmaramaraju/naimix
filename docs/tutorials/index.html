How videos work in these docs

Videos are plain MP4 files in the docs/videos/ folder, played with the browser's built-in player. Nothing is uploaded anywhere, and the docs work offline from file://.

To add or replace a video:

  1. Record your screen (macOS: Shift+Cmd+5). Aim for under two minutes per task.
  2. Export as H.264 MP4. If needed: ffmpeg -i in.mov -c:v libx264 -crf 28 -preset veryfast -c:a aac -movflags +faststart out.mp4
  3. Save it in docs/videos/ with the file name a page expects.
  4. Optionally add a poster image in docs/images/ and a captions file in docs/videos/ (.vtt).

To put a video on any page, add this where you want it:

<figure class="video" data-src="videos/my-tutorial.mp4"
        data-poster="images/my-tutorial.png"
        data-captions="videos/my-tutorial.vtt"
        data-title="What the video shows"></figure>

data-src is relative to the docs/ folder, whatever the page's own depth. Until a file exists, the page shows a "Video not added yet" placeholder naming the exact path to drop it at.

Re-recording automatically

The two videos here were generated by scripts that drive the real console UI against sample data, so they can be regenerated when the UI changes. See docs/recorder/README.md. Captions are included as .vtt files; turn them on in the player.

Keep the repo light: MP4 files grow quickly. Consider adding docs/videos/*.mp4 to .gitignore or using Git LFS if you commit many.
