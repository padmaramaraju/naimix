Create an XML gateway

A gateway is a reusable connection to a backend. In about a minute you will add one for an XML-over-HTTP service.

Steps

  1. Sign in. Open the console and enter your console token.
  2. Open Gateways. In the Shared Collection, open Gateways. This lists existing gateways. Click + Add to create a new one.
  3. Name it. Integrations refer to the gateway by this name. Example: customerXml.
  4. Set the kind to xml. The fields below change to match.
  5. Base URL. The root address every integration on this gateway will call. Example: https://api.example.com/xml.
  6. Headers (optional). Sent with every request through this gateway. Example: Accept = application/xml.
  7. Common parameters. These become {name} placeholders for every integration on this gateway. Example: apiVersion = v2.
  8. Save. Click Save gateway. It now appears in the Gateways list with type xml.

Next: create an integration that calls this gateway. See Integrations.

The same thing as YAML

gateways:
  customerXml:
    kind: xml
    baseUrl: https://api.example.com/xml
    headers:
      Accept: application/xml
    commonParams:
      apiVersion: v2
